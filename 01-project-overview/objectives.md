# Objectives

All objectives below are PLANNED assignment outcomes.

- Trace 20 distinct stories to functional requirements, sprint work and verification evidence.
- Demonstrate public discovery and account/profile workflows with authorization failure cases.
- Verify post → apply → select → message → complete → review integration.
- Verify trust controls and administrator moderation without exposing private conversations.
- Maintain agendas, real attendance/minutes, recording links and daily remaining-effort updates for scheduled events.
- Prepare readable UML, honest sprint reviews and a complete submission package by the stated deadline.

Success is assessed using acceptance criteria, the Definition of Done and real Product Owner review. No objective is marked achieved in advance.
